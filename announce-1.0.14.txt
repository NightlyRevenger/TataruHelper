:1_1: Tataru Helper 1.0.14 :1_1:

If TataruHelper wouldn't start at all and Windows showed only an empty "Unknown Hard Error" box — this build fixes it.

It happened on Windows 10 with updates turned off: the app asked Windows for a stack-protection feature that older Windows 10 doesn't fully support, and was shut down before it could open. It no longer asks for it, so no Windows updates are needed.

Thanks to the player who sent logs and error codes until we found it.

If something isn't working, or isn't working the way you think it should — tell us and we'll fix it.
