:1_1: Tataru Helper 1.0.13 :1_1:

If the installer told you "application install hook failed", or the app answered with "Unknown Hard Error" and never opened — that was our bug, and this build fixes it.

The app declared up front that it requires administrator rights, and Windows then refused to let the installer start it at all. It asks for them after starting now, which is what it should have done from the beginning. Nothing changes while you use it: it still runs as administrator, because it reads the game's memory.

If something isn't working, or isn't working the way you think it should — tell us and we'll fix it.

-----------

Если установщик писал "application install hook failed", или приложение отвечало "Unknown Hard Error" и не открывалось — это была наша ошибка, и эта версия её чинит.

Приложение заранее требовало права администратора, и из-за этого Windows не давала установщику его запустить. Теперь оно просит права уже после старта, как и следовало с самого начала. В работе ничего не меняется: приложение по-прежнему идёт с правами администратора, ведь оно читает память игры.

Если у вас что-то не работает или работает не так, как вам кажется — пишите, будем фиксить.
